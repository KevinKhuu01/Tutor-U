The Mission:
To create an AI powered interactive learning tool to help students better understand their material. Students input their class content in module 1 (The Study Room) and the Tutor creates a "lesson" on the left with each slide aiming to build conceptual and process understanding. Slides go from broad to detailed with students being able to chat to the Tutor about any of the slides.

Following the development completion of the first mode, implementation of the second and third mode will begin. The second mode will feature a practice question module still with the chat box on the right. The third module will provide mock exam content based on previous conversations with a timer on the right.
